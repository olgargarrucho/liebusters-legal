# LieBusters — Web legal y marketing

Sitio estático para App Store Connect (GitHub Pages).

## URLs (tras publicar)

Sustituye `liebusters-legal` por el nombre real del repositorio si es distinto.

| Campo en App Store Connect | URL |
|---|---|
| **URL de marketing** | `https://olgargarrucho.github.io/liebusters-legal/` |
| **URL de soporte** | `https://olgargarrucho.github.io/liebusters-legal/support.html` |
| **URL de la política de privacidad** | `https://olgargarrucho.github.io/liebusters-legal/privacy.html` |

## Publicar en GitHub Pages

1. Crea un repositorio **público** en GitHub, por ejemplo `liebusters-legal`.
2. Sube el contenido de esta carpeta a la raíz del repo (no la carpeta en sí, sino los archivos dentro).
3. Ve a **Settings → Pages**.
4. **Source:** Deploy from a branch → `main` → `/ (root)`.
5. Espera 1–2 minutos y comprueba las URLs.

## Archivos

- `index.html` — Página de marketing
- `support.html` — Soporte y contacto
- `privacy.html` — Política de privacidad
- `styles.css` — Estilos compartidos

## Nota

Actualiza el enlace de App Store en `index.html` cuando tengas el ID real de la app publicada.
